留白 · 第二部分网页 API Key 设置

1. 打开 http://127.0.0.1:8001/ 并登录本机最早创建的账号。
2. 首页任务标题下方有 DeepSeek 辅助拆分卡片，点击「DeepSeek 设置 ↗」。
3. 粘贴 API Key，核对模型，点击「验证并保存」。通过后显示验证时间，密钥输入框自动清空。
4. 已经配置过时，密钥框留空即可验证原配置。输入新密钥表示验证成功后替换原配置。
5. 返回任务的「分析与拆分」，确认发送内容并生成新草稿。此窗口也可直接打开密钥设置。

验证只访问模型列表，不生成任务；验证成功不代表账户余额充足，也不能保证以后网络或服务始终正常。
密钥仅存第二部分本机配置，不回显、不进入浏览器持久存储、不上传 GitHub。原有配置使用本机共享方式，其他账号只读，初始账号管理。环境变量优先时页面只验证现有配置。
关闭设置或退出登录会清空输入；已经提交的验证可能仍会完成，重新打开设置即可核对状态。验证失败时按页面原因处理，旧任务和已有步骤不受影响。

代码、回归测试和验收证据保存在第二部分，第一部分保持独立。
