# 留白 · 第一部分本地运行版

账号独立的任务空间：注册/登录/退出、创建与编辑、待选择/当前/暂停/历史、状态足迹、每周投入估计。尚未加入负载分析、AI、学习调度、永久删除。

## 运行

最方便的方式：在项目文件夹中双击 **`打开留白.command`**。入口会自动启动服务并打开浏览器；已经运行时直接打开，不重复启动。终端窗口可以关闭，服务继续在后台运行。请保持入口与 `taskflow` 文件夹放在一起。

在本目录执行 `./start.sh`，然后打开 http://127.0.0.1:8000 。第一次运行会创建虚拟环境、安装固定版本运行依赖并初始化数据库。需要 Python 3.12+（实际验证为 3.14.4）。已有 `.venv` 但缺依赖时执行 `.venv/bin/python -m pip install -r requirements.txt`。

网页里创建自己的账号即可使用，没有预置账号或默认密码。用户名使用 3–32 位英文字母、数字或下划线；密码至少 10 位并通过 Django 的密码强度检查。

本机开发服务器只监听回环地址。`--insecure` 仅让 Django 在 DEBUG=False 时提供本地静态文件，不会关闭 CSRF 或账号验证。本版未做公网生产部署。

## 数据与隔离

- `.local/tasks.sqlite3` 保存账号、会话、任务和状态历史；`.local/secret-key` 是随机生成的本机应用密钥，初始文件权限 0600。它们均不属于源码。
- 后端所有任务读写都按当前会话账号过滤，跨账号查询或修改返回 404；客户端不能提交任务归属字段。
- 会话 Cookie 为 HttpOnly、SameSite=Lax；所有写操作校验 CSRF。当前为本地 HTTP；未来 HTTPS 部署应设置 `HTTPS_ONLY=1`，并更换生产服务器与限流方案。
- 任务修改携带版本号。过期版本返回 409，不覆盖已保存的新内容；状态变更与任务更新在同一事务内。
- 创建请求按“账号 + 请求标识”去重。未估计为 null，0 分钟保留为 0；每周投入上限 10080 分钟仅是每周时间输入范围，绝非健康或工作能力上限。
- 草稿仅保存在当前页面内存，登录失效时绑定原账号恢复；切换账号不会显示它。关闭/刷新页面会提示未保存修改，但本版不提供长期草稿保存。
- 界面当前账号与共享会话不一致时，后端拒绝请求；重新切回标签页会核对身份。
- 登录限流使用进程内缓存，适用于此单实例本地版本；不是分布式防护方案。

备份时先停止服务器，复制 `.local/`；恢复时停止服务器，再恢复整个目录。不要删除数据库或密钥来“重启应用”。

## 可复现验收

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
./tools/verify.sh
```

工具链还需要 Node.js（检查 JavaScript 语法）和已安装的 Google Chrome（浏览器验收）。测试使用独立临时数据库，不向你的使用数据库写入示例任务。完整验收包含 API/性质/并发测试、Python 类型与格式检查、覆盖率、七个手工变异、两个随机顺序测试、浏览器桌面/手机操作、服务器重启持久化、迁移回退重建、依赖审计与源码哈希。

`SPEC.md` 记录场景和失败模型；`EVIDENCE.md` 记录最终结果、覆盖范围与限制。`evidence/` 包含可复查日志和截图，截图中的账号与任务来自独立验收环境。

## 目录

- `tasks/models.py`：任务与状态记录。
- `tasks/services.py`：归属限制、校验、幂等与事务更新。
- `tasks/views.py`：账号和 JSON API。
- `templates/index.html`、`static/`：原生中文网页、样式与交互。
- `tasks/tests/`、`tools/`：可执行验收与重复验证。

当前没有自动初始化 Git 或创建提交；源码版本由 `tools/source_state.py` 生成 SHA-256，排除运行数据、工具缓存和生成证据。
