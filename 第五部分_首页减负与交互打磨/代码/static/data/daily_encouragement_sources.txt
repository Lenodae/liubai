二、筛选与改动

先按中文长度、主题及排除词筛选，再逐条阅读候选，另进行独立复核。
保留循序渐进、自我接纳、休息、学习与探索、日常生活、温暖友情及清朗山水等内容。
剔除明显的悲观绝望、死亡暴力、失恋、羞辱比较、过劳要求、强迫积极、夸大成功保证等内容。
未选歌词、影视台词分类；发现原创分类里明确标注为歌词、影视或现代文学摘录的内容也予以排除。
诗词仅选古代作品；山水、清欢与闲适语句用于让每日阅读不只围绕绩效和完成任务。
筛选是产品文案判断，不代表对每条提交记录的著作权或古籍归属作独立认证。

本地文件 daily_encouragement.json 含完整的 300 条选定数据，可以直接下载、查看和修改。
正文 text 逐字保留上游 hitokoto 字段，没有改写或将新编文案冒充下载内容。
source 保留上游 from；author 只在上游 from_who 明确存在时保留，不将投稿者 creator 冒充作者。
id 为 hitokoto- 加上游 UUID；upstream_id、upstream_category 与 source_url 保留可核对的来源。
每条 source_url 指向 https://hitokoto.cn/?uuid=对应UUID。
使用 Python random.Random(20261015) 固定打散候选顺序，并将 upstream_id=10062 放在首位。
当天句子的选择由本地日期轮换逻辑决定，不需要密钥，也不请求外部模型。
