# 留白 · 第五部分：首页减负与交互打磨

双击上一级「打开留白.command」，打开 http://127.0.0.1:8004/ 。设计书、SPEC 和验收说明保存在本部分 `../规划书/`。

## 这版怎么用

首页先看预算。圆盘右侧直接填写小时和分钟；「预算怎么填」随时解释总预算、留白、计划与实际时间。总预算20小时、留白2小时、进行中6小时，可再安排12小时，时间负载约33%；实际记1小时不会再次扣计划。任务来源明细可展开，缺时间会提示。深入分析页保留完整摘要。

预算下方和进行中任务卡直接展示当前步骤、完成标准与下一步。做完后勾选即可登记，成功后推进到下一步，并提供「撤销刚才完成」及查看/修改记录入口。有前置依赖的下一步标明解锁条件；暂停、放弃和依赖未满足的步骤不会被自动选中。本机记住当前账号最近查看或完成步骤的进行中任务；没有可用记忆时按优先级选择一项。搜索任务不会改变上方推荐。

勾选只确认当前步骤，实际耗时仍在「记录耗时」中单独填写；最后一步完成后仍由你核对整个任务，预算不会因此自动释放。网络结果不确定时，点击「重试同一次操作」核对原回执，不会重复登记。撤销仅针对本次页面中最近完成的一步；更早的记录可在「全部步骤 / 完成记录」查看、修改或撤销。

每日足迹默认收起，可以随时展开最近12周。今日签到、看看今天、全年、失败重试均保持可用。任务进展和实际投入沿用原始账本，不因签到增加预算或耗时；日期仍按北京时间。每个账号单独记住本机的足迹展开偏好和最近任务ID，浏览器不保存任务正文。

## 独立保存与现有账号

本部分拥有独立代码、虚拟环境、数据库、签名密钥和8004端口，Cookie为 `taskflow5_session` / `taskflow5_csrf`。前四部分代码、规划和数据库保留，可分别运行。

本机首次启用用 SQLite 一致性快照复制第四部分的账号、任务、步骤、完成记录、耗时、预算以及签到和幂等回执。原账号密码可继续使用，需要在新版重新登录。DeepSeek配置按原字节复制，无须发出新的付费验证请求。复制的排队/运行中AI请求标记为中断，避免重复执行。

本版数据在 `.local/tasks.sqlite3`；初始快照在 `.local/phase4-import-backup.sqlite3`。之后各版本各自保存，不自动同步。新克隆不含个人数据库、密钥或环境；首次启动为空库，需要注册并配置DeepSeek。

## 启动与验证

运行 `bash start.sh`。依赖固定在 `requirements*.txt`，Python 3.14。导入已有第四部分数据须在首次启动前运行 `.venv/bin/python tools/initialize_from_phase4.py`；已有数据库或备份会拒绝覆盖。旧第三部分导入CLI在本版停用，勿用来同步数据。

开发依赖安装后，`bash tools/verify_phase5.sh` 在临时数据库运行全套后端、静态、纯逻辑性质/变异、浏览器和合成导入恢复检查。Playwright需要本机Chrome或安装Chromium；测试不调用付费AI、不改个人任务。浏览器依次运行以免固定端口冲突。

首页布局新增代码为 `static/overview_focus_core.js`、`overview_focus.js/css`、`overview_budget.js/css`，并为原app/execution/load/footprints添加入口与布局调整。2026-10-17 增加 `execution/overview.py` 只读步骤摘要和 `static/inline_steps.js/css` 快捷完成组件；沿用原完成/撤销接口，无新增数据库模型、写入接口或运行依赖。设计书先于产品实现生成。

当前步骤更新的规范见 `INLINE_STEPS_SPEC.md`，验证见 `INLINE_STEPS_EVIDENCE.md`；复现命令为 `bash tools/verify_inline_steps.sh`。

实际验证结果见 `EVIDENCE.md`，完整日志和测试截图见 `evidence/`。新JS交互不以继承的Python覆盖率替代验证；未覆盖的浏览器和失败模式会明确列出。
