## 在 Mac 上运行

安装 Python 3 后，双击根目录 `打开留白.command` 默认启动第四部分。也可以进入各部分目录，双击对应入口。首次启动自动创建虚拟环境、安装运行依赖并创建空数据库。

GitHub 中不包含本机用户账号、任务数据库、登录会话、密钥、虚拟环境和运行日志。首次克隆需要重新注册账号；电脑上的原始数据仍保留在各自 `代码/.local/` 目录。

第二、第三、第四部分登录后可在首页顶部「DeepSeek 设置 ↗」输入密钥并验证保存，也保留 `配置 DeepSeek.command` 入口。网页配置由本机初始账号管理，密钥仅保存在本机，不要提交到仓库。手工拆分、规则分析、完成登记和耗时账本不依赖模型服务。

## 第二部分使用流程

保存目标与条件 → 手工拆分或生成草稿 → 编辑并采纳 → 步骤执行 → 记录实际耗时 → 核对完成。

- 每周计划投入、预计总耗时和实际耗时分别记录。
- 父任务汇总各子步骤的有效耗时，避免重复登记。
- 完成、撤销、补记、修改和删除保留相应历史。
- AI 结果先进入草稿，由用户采纳；不会自动改变任务状态或实际耗时。

## 规划与验证

各部分 `规划书/` 中保存架构 PDF、实施说明、SPEC 和 EVIDENCE，第四部分实施规范和验收说明保存在自己的规划书中；最新测试结果见第四部分 EVIDENCE。真实 DeepSeek 付费生成与密钥连接验证分别记录，不把模拟响应当作真实生成结果。

安装 `requirements-dev.txt` 后，可在各自代码目录运行 `bash tools/verify.sh`。证据日志、截图和覆盖率文件可重新生成；本机目录迁移/数据隔离检查依赖原电脑的历史快照，新克隆不能直接复现这项历史状态检查。

第三部分初始化已复制本机第二部分账号与任务快照，之后两边独立保存、互不自动同步；本机已有 DeepSeek 配置已补迁移到第三部分独立保存；首次克隆仍需自行配置。

## 第四部分：每日足迹

今日鼓励旁可签到，预算圆环后、任务列表前展示最近12周的足迹，支持查看全年、按日期查看真实耗时与完成步骤。签到、休息和实际进展分别展示；签到不改变任务、预算或耗时。详情见 [第四部分使用说明](第四部分_每日足迹与签到/代码/README.md)。

本机第四部分已从第三部分一致性快照复制账号与业务数据，已有DeepSeek配置独立保留；原账号密码可沿用，需要重新登录。此后三、四部分各自保存，不自动同步。第四部分备份在其 `代码/.local/phase3-import-backup.sqlite3`。第四部分完整验证入口为 `bash tools/verify_phase4.sh`。
